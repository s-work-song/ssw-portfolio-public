# 자기소개서 경력 전환 섹션

## 범위

- 작업 브랜치: `feature/career-gap-preview`
- 위치: 자기소개서의 기존 서사와 Core Values 사이
- 섹션: 경력의 전환점
- 흐름: 직장생활을 멈춘 이유, 그동안 정리한 생각, 다시 시작하려는 이유

활동 목록이나 연구 타임라인을 추가하는 작업이 아니다. 상위 탐색 탭, 이력서와 연구 본문, 운영 챗봇 지식과 도구 계약은 변경하지 않는다.

## 원고 기준

사용자가 제공한 이전 이력서의 구직 사유를 바탕으로 세 부분의 원고를 구성했다. 기존 지식의 개인 연구 활동만으로 직장생활을 멈춘 이유를 추측하지 않는다.

근무 조건과 상세 기술 이력은 이 섹션에 섞지 않는다. 구체적인 모델명, 공개 시점과 서비스 중단 경위는 확인 전에는 본문에 넣지 않는다. 제품 출시 순서가 아니라 본인이 도구를 접하고 생각을 바꾼 흐름으로 정리한다.

2026-10-06 사용자가 현재 원고의 운영 배포를 승인했다. GPT 챗봇을 처음 사용한 느낌, LLM 기반 코드 자동 완성, 에이전틱 코딩을 접한 흐름을 반영하고 공개 화면에서는 검토용 초안 표시를 제거한다.

비공개 백엔드, 챗봇 지식과 인터뷰 메모는 이번 배포에 포함하지 않는다.

## 확인

- 로컬 개발 서버: `http://127.0.0.1:3000/about-me/cover-letter/`
- 직접 위치: `#cover-letter-career-turning-point`
- 구조 테스트: `node --test src/components/about/careerTurningPointPreview.test.mjs`
- 전체 프런트엔드 테스트: `npm test`

운영 배포는 공개 저장소의 `main`에 반영한 뒤 기존 GitHub Pages 워크플로로 진행한다.
