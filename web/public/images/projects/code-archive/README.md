# 코드 아카이브 이미지

코드 아카이브 카드 캐러셀에 사용할 공개 가능한 문서·탐색·검증 화면을 둔다.

- 권장 형식: WebP, PNG, JPG
- 권장 비율: 16:9
- 권장 크기: 1600×900px 전후
- 파일명 예시: `01-catalog.webp`, `02-algorithm.webp`, `03-validation.webp`
- 공개 저장소에 없는 코드·메타데이터·검증 자료는 이미지에 포함하지 않는다.

파일을 추가한 뒤 `src/data/about.ts`의 코드 아카이브 `gallery.images`에 경로·대체 텍스트·설명을 등록한다.
