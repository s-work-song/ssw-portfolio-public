# 게임 모음 플랫폼 이미지

게임 모음 카드 캐러셀에 사용할 공개 가능한 플랫폼·샘플 게임 화면을 보관합니다.

- 권장 형식: WebP, PNG, JPG
- 권장 비율: 16:9
- 권장 크기: 1600×900px 전후
- 파일명 예시: `01-platform.webp`, `02-omok.webp`, `03-skyward.webp`
- 개발 중인 화면의 디버그 정보나 비공개 자산은 이미지에서 제거합니다.

파일을 추가한 뒤 `src/data/about.ts`의 게임 모음 `gallery.images`에 경로·대체 텍스트·설명을 등록합니다.
