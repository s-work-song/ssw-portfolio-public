# 계절 입자 레이어

눈과 낙엽·벚꽃·비가 다음 공통 규칙을 사용한다. 낙엽·벚꽃·비는 `runSeasonParticles`에서 전체 화면과 스타일 가이드 견본의 렌더러를 공유한다.

- `particleDensityTransition`: 목표 수를 향해 입자를 간격을 두고 추가하거나 서서히 흐리게 한다. 첫 로딩과 다시 켜기는 빈 배열과 목표 수 0에서 시작하고, 효과가 정한 높이별 시작 시간으로 분산한다.
- `particlePlaneTransition`: 앞쪽 입자를 뒤로 보낼 때만 페이드한다. 숨기기를 끄면 기존 입자는 원래 층에 두고 새 입자부터 앞에 보낸다. 뒤쪽 입자를 가리는 일은 카드와 브라우저의 레이어 순서에 맡긴다.
- `particleScrollShift`: 전체 화면 캔버스는 화면에 고정이지만 입자는 스크롤한 만큼 반대로 옮겨 페이지에 붙어 있는 것처럼 보이게 하고, 화면 밖으로 밀려난 입자는 반대쪽 끝으로 돌린다. 견본은 쓰지 않는다.
- `ParticleCanvases`: 카드 앞뒤 두 캔버스와 스프라이트 그리기를 제공한다. 전체 화면의 카드 뒤 캔버스는 `body` 바로 아래에, 견본은 배경과 카드를 함께 그리는 격리된 상자에 둔다.

효과를 그리는 쪽에서 테마와 사용자 설정, 입자 모양·속도·움직임, 화면 위 생성 위치, 밀도와 전환 시간을 정한다. 모션 허용 여부는 `seasonMotion`을 따른다.
