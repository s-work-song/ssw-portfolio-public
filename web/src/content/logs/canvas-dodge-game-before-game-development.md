# 그래프를 그리다가 작은 게임을 만들어 봤습니다

2021년경 웹 개발 경력 2년차 전후에 만든 작은 Canvas 게임입니다. 당시에는 계약 기간이 남아 있어 웹 개발을 계속하고 있었지만, 이후 게임 개발을 시작하기 전에 브라우저에서 어느 정도까지 직접 구현할 수 있는지 가볍게 알아보고 싶었습니다.

비슷한 시기에 HTML Canvas로 그래프를 그리고 베지어 곡선(Bezier curve)을 다뤄본 기억이 있습니다. 오래전 작업이라 정확한 순서는 흐릿하지만, 화면에 직접 도형과 선을 그려보면서 이 방식이면 간단한 게임도 만들 수 있겠다는 생각으로 피하기 게임까지 만들어 본 것으로 기억합니다.

처음부터 큰 결과물을 계획한 작업은 아니었습니다. 게임 개발을 시작하기 전 가능성을 확인하는 실험이자 퇴근 후 심심풀이에 가까웠습니다.

## 퇴근 후 이틀 동안 만든 단일 HTML 게임입니다

하루에 2~3시간씩 이틀 정도, 합하면 약 5시간을 들였던 것으로 기억합니다. 하나의 HTML 파일 안에 화면과 동작을 함께 구성했습니다.

구현한 기능은 다음과 같이 단순합니다.

- 캐릭터 이동
- 위에서 떨어지는 장애물 회피
- 캐릭터와 장애물의 기초적인 충돌 처리
- 생존 시간 기록
- 키보드 방향키와 화면 방향 버튼 조작

복잡한 물리나 도형별 충돌 알고리즘을 깊게 연구한 작업은 아닙니다. Canvas에서 캐릭터와 장애물을 직접 움직여 보며 게임에 필요한 기초적인 충돌 처리를 알아볼 수 있었다는 데 의미가 있습니다.

## 이후 Unity 기능을 이해하는 데 도움이 됐습니다

이 작업 직후 게임 개발로 전환한 것은 아닙니다. 당시 계약 기간 동안 웹 개발을 계속했고, 실제 게임 개발은 2022년에 시작했습니다.

다만 Canvas에서 이동과 충돌을 직접 처리해 본 경험은 이후 Unity의 물리와 충돌 기능을 사용할 때 도움이 됐습니다. 엔진이 제공하는 기능을 처음 접했을 때도 입력과 이동, 충돌 판정이 어떤 역할을 하는지 이해하기가 조금 더 수월했습니다.

완성도 높은 게임을 만들었다기보다, 이후 게임 엔진을 배우기 전에 가장 기초적인 동작을 직접 구성해 본 경험으로 남아 있습니다.

## 지금은 몇 분 안에도 만들 수 있는 코드라고 생각합니다

당시에는 퇴근 후 약 5시간을 들여 손 코딩으로 작성했습니다. 현재 같은 수준의 작은 게임은 AI 에이전트를 활용하면 기본 형태를 몇 분 안에도 만들 수 있을 것 같습니다.

과거 작업을 다시 실행해 보면서 에이전틱 코딩 전후의 생산성 차이를 구체적으로 실감했습니다. 예전에는 이틀 동안 직접 입력하고 확인해야 했던 결과가 이제는 짧은 요청과 검증으로 만들어질 수 있습니다.

그렇다고 당시의 손 코딩 경험이 의미 없어졌다고 생각하지는 않습니다. 직접 이동과 충돌을 구현해 본 경험이 이후 Unity 기능을 이해하는 데 도움이 됐고, 지금도 도구나 AI가 만든 결과가 어떤 역할을 하는지 판단하는 배경으로 남아 있기 때문입니다.

이 작업은 지금의 구현 능력을 보여주기 위한 최신 프로젝트라기보다, 에이전틱 코딩 이전에 직접 원리를 확인하며 만들었던 작은 학습 기록에 가깝습니다.
